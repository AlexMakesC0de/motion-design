A motion-design studio for AI video and images, on your own computer.

Plan a film scene by scene, swap a character into any clip, keep the same face across every shot, and see the price of every job before it runs. Use the web studio, the terminal, or just ask Claude Code or Codex.

What's inside

Films, scene by scene

Agree a brief, plan the shots, make a storyboard of stills, film them, review each take and cut the film with music and captions.

Openjutsu Beta

Swap a person, outfit, object or background in a clip with Wan 2.2 Animate or MiniMax H3. Cut the part you want first, and keep a Motion Library of clips.

AI Influencers

Make a face, then a three-panel character sheet, so the same person comes back in every image and video.

17 Looks

Camera, pacing and sound in one pick: neo-noir, claymation, phone selfie, vintage 16mm and more, from the studio, the CLI or MCP.

Every job priced first

Each paid job is priced before it is sent and checked against a daily cap and a per-job limit, from the studio, the CLI or an agent.

Agents built in

An MCP server gives Claude Code, Codex and Claude Desktop the same tools as the studio, plus your own skill library as slash commands.

Quick start

git clone https://github.com/AlexMakesC0de/shard-motion-design-studio.git
cd shard-motion-design-studio
node install.mjs            # --dry-run shows what it would change first
kie doctor                  # one free balance check, generates nothing
npm --prefix web install && npm run studio   # http://127.0.0.1:4317

Needs Node 22+ and a kie.ai API key. Runs on your machine and only answers your machine. MIT licensed.
