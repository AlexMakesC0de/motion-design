Studio v2: low-fidelity layout

Boxes only, no colour or polish. These frames decide where things go and what you click. Red numbers match the notes under each frame. Each note names the Mobbin screen the idea comes from.

The big change: each film gets one home with four steps across the top: Brief → References → Shots → Finish. Today the same film is split across Studio, Storyboard, Takes and Films. Quick one-off generations get their own Create page. The chat becomes a drawer you open when you need it.
