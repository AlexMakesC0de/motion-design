## How the chat reaches the page

**Transport: the existing SSE stream, with a new `chat` event** carrying `{ film, busy, entry }`. A turn runs on the server, not in the request that started it: `POST /api/chat/:film` saves the user's line and answers with it at once, and every later change (a text delta, a tool step going from running to done, the end of the turn) is an event. Compared with a streamed POST response:

- Leaving the tab, reloading or opening a second tab does not kill the turn or lose its lines; `GET /api/chat/:film` returns the saved entries plus the turn in progress, and the page asks again on every `hello` (after a reconnect).
- The stream already has the key refresh, the reconnect with backoff and the Host check; a second long-lived response type would need all three again.
- Jobs the chat starts already reach the feed as `job` events on the same stream, so the panel and the feed stay in step.

Entries keep their id while they change, so the page replaces an entry by id (a streaming assistant line grows; a tool step gains its result). The turn's entries are written to `chat.jsonl` when it ends, in the order they began; the user's line is written when it is sent.

**One transcript shape for both backends** (`web/server/chat/transcript.mjs`):

```
{ id, kind: "user",      at, text }
{ id, kind: "assistant", at, text, streaming }
{ id, kind: "tool",      at, name, args, result, state: "running" | "done" | "failed" }
{ id, kind: "notice",    at, text, tone: "error" | "info" }
```

`args` and `result` are short lines for people, built from the MCP call and result: `argsLine` keeps model, preset, duration ("4s"), resolution, aspect ratio, job id and a clipped prompt; `resultLine` gives a price for `estimate`, "`<job id> <state>`" for a submit, "`<outcome> $<cost>`" for `wait_job`, and one line per core error code (2: "stopped by the limits, nothing spent"). Both are clipped and redacted.

**Spending.** The chat never asks before spending: the system prompt says the user's limits are checked on every paid call, so go ahead. When a tool returns code 2, the backend ends the turn (the OpenAI loop stops calling the model; Codex gets `turn/interrupt`) and the assistant's last line is core's reason plus "I've stopped here: raise the limit in Settings, or ask me for something cheaper."

`codex app-server` speaks JSON-RPC over stdio, one JSON object per line, with no `"jsonrpc"` field (checked against codex-cli 0.154.0 with `initialize` and `account/read` only). `web/server/chat/codex.mjs` starts it once and reuses it.

```js
// An MCP client wired to createServer() in this process, over the SDK's
// in-memory transport. The studio's API-key chat calls the tools through it,
// so the chat sees exactly the tools, descriptions and instructions that
// Claude Code and Codex see. It lives in mcp/ so the SDK resolves from
// mcp/node_modules; the studio server itself has no dependencies.
import { Client } from "@modelcontextprotocol/sdk/client/index.js";
import { InMemoryTransport } from "@modelcontextprotocol/sdk/inMemory.js";
import { createServer } from "./server.mjs";

/**
 * Connect a client to a fresh server. `deps` and `catalog` go to
 * createServer() unchanged (tests pass provider stubs). Resolves
 * { client, close }.
 */
export async function connectInProcess({ deps = {}, catalog, name = "motion-design-studio" } = {}) {
  const server = createServer(catalog ? { deps, catalog } : { deps });
  const client = new Client({ name, version: "0.1.0" });
  const [clientSide, serverSide] = InMemoryTransport.createLinkedPair();
  await Promise.all([client.connect(clientSide), server.connect(serverSide)]);
  return {
    client,
    close: async () => {
      await client.close();
      await server.close();
    },
  };
}
```

```js
#!/usr/bin/env node
// Regenerate the Codex app-server protocol types the chat's subscription
// backend relies on, from the installed codex CLI. Runs
// `codex app-server generate-ts` into a temp folder, then copies only the
// files the backend uses (and every file they import) into
// server/chat/codex-protocol/, plus methods.json: the method names of every
// client request, server request and server notification in this version.
// Free and offline: generating types starts no server and no thread.
//
//   npm --prefix web run codex-protocol
import { cpSync, mkdirSync, mkdtempSync, readFileSync, rmSync, writeFileSync } from "node:fs";
import { spawnSync } from "node:child_process";
import { tmpdir } from "node:os";
import { dirname, join, normalize } from "node:path";
import { fileURLToPath } from "node:url";

const OUT = join(dirname(fileURLToPath(import.meta.url)), "..", "server", "chat", "codex-protocol");

/** The shapes codex.mjs reads or writes. Each pulls in what it imports. */
const ROOTS = [
  "InitializeParams.ts",
  "InitializeResponse.ts",
  "ClientNotification.ts",
  "v2/GetAccountParams.ts",
  "v2/GetAccountResponse.ts",
  "v2/ThreadStartParams.ts",
  "v2/ThreadStartResponse.ts",
  "v2/ThreadResumeParams.ts",
  "v2/TurnStartParams.ts",
  "v2/TurnStartResponse.ts",
  "v2/TurnInterruptParams.ts",
  "v2/ListMcpServerStatusParams.ts",
  "v2/ListMcpServerStatusResponse.ts",
  "v2/ItemStartedNotification.ts",
  "v2/ItemCompletedNotification.ts",
  "v2/AgentMessageDeltaNotification.ts",
  "v2/TurnCompletedNotification.ts",
  "v2/ErrorNotification.ts",
  "v2/CommandExecutionRequestApprovalResponse.ts",
  "v2/FileChangeRequestApprovalResponse.ts",
  "v2/PermissionsRequestApprovalResponse.ts",
  "v2/McpServerElicitationRequestResponse.ts",
  "v2/ToolRequestUserInputResponse.ts",
  "v2/DynamicToolCallResponse.ts",
  "ApplyPatchApprovalResponse.ts",
  "ExecCommandApprovalResponse.ts",
];

const methods = (text) => [...text.matchAll(/"method": "([^"]+)"/g)].map((m) => m[1]);

const tmp = mkdtempSync(join(tmpdir(), "codex-ts-"));
try {
  const gen = spawnSync("codex", ["app-server", "generate-ts", "--out", tmp], { encoding: "utf8" });
  if (gen.status !== 0) {
    process.stderr.write(`codex app-server generate-ts failed (is codex installed?):\n${gen.stderr || gen.error?.message}\n`);
    process.exit(1);
  }
  const version = spawnSync("codex", ["--version"], { encoding: "utf8" }).stdout.trim();
  const keep = new Set();
  const visit = (rel) => {
    if (keep.has(rel)) return;
    keep.add(rel);
    const text = readFileSync(join(tmp, rel), "utf8");
    for (const m of text.matchAll(/from "(\.[^"]+)"/g)) visit(normalize(join(dirname(rel), `${m[1]}.ts`)));
  };
  ROOTS.forEach(visit);

  rmSync(OUT, { recursive: true, force: true });
  for (const rel of [...keep].sort()) {
    mkdirSync(dirname(join(OUT, rel)), { recursive: true });
    cpSync(join(tmp, rel), join(OUT, rel));
  }
  const read = (f) => readFileSync(join(tmp, f), "utf8");
  const index = {
    generatedBy: version,
    clientRequests: methods(read("ClientRequest.ts")),
    clientNotifications: methods(read("ClientNotification.ts")),
    serverRequests: methods(read("ServerRequest.ts")),
    serverNotifications: methods(read("ServerNotification.ts")),
  };
  writeFileSync(join(OUT, "methods.json"), `${JSON.stringify(index, null, 2)}\n`);
  console.log(`${keep.size} type files and methods.json from ${version} in ${OUT}`);
} finally {
  rmSync(tmp, { recursive: true, force: true });
}
```

Create `web/server/chat/transcript.mjs`:

```js
// One transcript shape for the chat, whichever backend answers. Entries:
//   { id, kind: "user", at, text }
//   { id, kind: "assistant", at, text, streaming }
//   { id, kind: "tool", at, name, args, result, state: "running" | "done" | "failed" }
//   { id, kind: "notice", at, text, tone: "error" | "info" }
// A tool step's args and result are short lines for people, such as
// "minimax-h3 4s 480p" and "$0.16". History lives in runs/<film>/chat.jsonl,
// one JSON object per line, plus { kind: "codex-thread", threadId } lines the
// page never sees.
import { appendFileSync, existsSync, lstatSync, readFileSync } from "node:fs";
import { join } from "node:path";
import { runDir } from "../../../cli/lib/run.mjs";
import { EXIT, unknown } from "../../../cli/lib/errors.mjs";
import { redact } from "../../../cli/lib/redact.mjs";

export const CHAT_FILE = "chat.jsonl";
const KINDS = new Set(["user", "assistant", "tool", "notice"]);

/** A chat failure with one sentence for the page. `connect` means: show the two connection options. */
export class ChatError extends Error {
  constructor(message, { connect = false } = {}) {
    super(message);
    this.connect = connect;
  }
}

let seq = 0;
const newId = () => `c${Date.now().toString(36)}${(seq++).toString(36)}`;
const now = () => new Date().toISOString();

export const userEntry = (text) => ({ id: newId(), kind: "user", at: now(), text });
export const assistantEntry = (text = "", streaming = true) => ({ id: newId(), kind: "assistant", at: now(), text, streaming });
export const toolEntry = (name, args) => ({ id: newId(), kind: "tool", at: now(), name, args: argsLine(args), result: null, state: "running" });
export const noticeEntry = (text, tone = "error") => ({ id: newId(), kind: "notice", at: now(), text: redact(text), tone });

/**
 * The film's chat file. runDir checks the slug (code 1 for a bad one) and
 * keeps the folder inside runs/; a chat.jsonl that is a symlink is refused,
 * so a write can never land outside the film.
 */
export function chatPath(film, { create = false } = {}) {
  const file = join(runDir(film, { create }), CHAT_FILE);
  if (existsSync(file) && lstatSync(file).isSymbolicLink()) {
    throw unknown(`runs/${film}/${CHAT_FILE} is a link; the studio only writes plain files in a film.`);
  }
  return file;
}

/** The saved transcript, oldest first, and the film's Codex thread if it has one. A missing film or file is an empty chat. */
export function readChat(film) {
  const file = chatPath(film);
  const out = { entries: [], codexThread: null };
  if (!existsSync(file)) return out;
  for (const line of readFileSync(file, "utf8").split("\n")) {
    if (!line.trim()) continue;
    let rec;
    try {
      rec = JSON.parse(line);
    } catch {
      continue; // a torn last line from a crash; the rest is still good
    }
    if (rec?.kind === "codex-thread" && typeof rec.threadId === "string") out.codexThread = rec.threadId;
    else if (KINDS.has(rec?.kind) && typeof rec.id === "string") out.entries.push(rec);
  }
  return out;
}

/** Append records to the film's chat, making the film's folder if this is its first line. */
export function appendChat(film, records) {
  if (!records.length) return;
  appendFileSync(chatPath(film, { create: true }), records.map((r) => `${JSON.stringify(r)}\n`).join(""));
}

/** The saved user and assistant lines as model input, newest 40. Tool steps and notices stay on the page. */
export function historyMessages(entries, max = 40) {
  return entries
    .filter((e) => (e.kind === "user" || e.kind === "assistant") && e.text)
    .slice(-max)
    .map((e) => ({ role: e.kind, content: e.text }));
}

const clip = (s, n) => (s.length > n ? `${s.slice(0, n - 1)}…` : s);
const usd = (v) => `$${Number(v).toFixed(2)}`;
const firstLine = (s) => String(s ?? "").split("\n").find((l) => l.trim()) ?? "";
const firstSentence = (s) => firstLine(s).match(/^.*?[.!?](?=\s|$)/)?.[0] ?? firstLine(s);

// The arguments worth a glance, in this order. Prompts are clipped; runs are the film itself.
const SHOWN = ["model", "preset", "duration_s", "resolution", "aspect_ratio", "job_id", "name", "template", "video", "capability"];

/** "minimax-h3 4s 480p" from a tool's arguments. */
export function argsLine(args) {
  const a = args && typeof args === "object" ? args : {};
  const parts = [];
  for (const k of SHOWN) {
    const v = a[k];
    if (v == null || v === "" || typeof v === "object") continue;
    parts.push(k === "duration_s" ? `${v}s` : String(v));
  }
  if (Array.isArray(a.refs) && a.refs.length) parts.push(`${a.refs.length} ref${a.refs.length > 1 ? "s" : ""}`);
  if (typeof a.prompt === "string" && a.prompt.trim()) parts.push(`"${clip(a.prompt.trim(), 32)}"`);
  if (!parts.length && typeof a.run === "string") parts.push(a.run);
  return redact(clip(parts.join(" "), 120));
}

/** All text parts of an MCP tool result. */
export function resultText(result) {
  return (result?.content ?? [])
    .filter((c) => c?.type === "text")
    .map((c) => c.text)
    .join("\n");
}

/**
 * The typed core error in a tool result, or null. MCP results carry it in
 * _meta.error (and "Error <code>: <message>" in the text); Codex passes the
 * same result through. `code` is null for a failure that did not come from
 * core (Codex timing a tool out, say).
 */
export function failure(result) {
  if (!result?.isError && result?._meta?.error == null) return null;
  const text = resultText(result);
  const raw = result?._meta?.error?.code ?? text.match(/^Error (\d)\b/)?.[1];
  const message = text.replace(/^Error \d: /, "").split("\nNext:")[0].trim() || "The tool failed.";
  return { code: raw == null ? null : Number(raw), message };
}

const ERROR_LINES = {
  [EXIT.USAGE]: (m) => `refused: ${firstSentence(m)}`,
  [EXIT.BUDGET]: () => "stopped by the limits, nothing spent",
  [EXIT.UNKNOWN]: (m) => `refused: ${firstSentence(m)}`,
  [EXIT.PROVIDER]: (m) => `provider error: ${firstSentence(m)}`,
  [EXIT.UNCERTAIN]: () => "uncertain: still checking, do not resubmit",
};

/** The short result of a tool step: "$0.16", "j-20261030-7f3a running", or one line saying what failed. */
export function resultLine(name, result) {
  const f = failure(result);
  if (f) return redact(clip((ERROR_LINES[f.code] ?? ((m) => `failed: ${firstSentence(m)}`))(f.message), 140));
  const sc = result?.structuredContent ?? {};
  if (name === "estimate" && "estimateUsd" in sc) return sc.estimateUsd == null ? "no estimate" : `${usd(sc.estimateUsd)}${sc.allowed ? "" : " · not allowed"}`;
  if ((name === "generate_video" || name === "generate_image") && sc.localJobId) return `${sc.localJobId} ${sc.state}`;
  if (name === "wait_job" && sc.outcome) return `${sc.outcome}${sc.actualUsd != null ? ` ${usd(sc.actualUsd)}` : ""}`;
  return redact(clip(firstLine(resultText(result)), 100)) || "done";
}

/**
 * What the assistant says when a limit refuses a job (code 2). The chat
 * never asks before spending, so a refusal ends the turn: core's reason,
 * then the way out.
 */
export function budgetSentence(message) {
  const reason = String(message).split(/\s*Ask the user/)[0].trim();
  return `${reason} I've stopped here: raise the limit in Settings, or ask me for something cheaper.`;
}

/**
 * The sink a backend writes one turn into. Backends name things by their own
 * keys (an OpenAI item id, a Codex item id, a call id); the sink turns them
 * into entries and calls `onEntry(entry)` on every change, so the page sees
 * text stream in and tool steps go from running to done. `entries` is the
 * turn's entries in the order they began.
 */
export function createTurnLog(onEntry) {
  const entries = [];
  const byKey = new Map();
  const add = (key, entry) => {
    byKey.set(key, entry);
    entries.push(entry);
    return entry;
  };
  return {
    entries,
    text(key, delta) {
      const e = byKey.get(key) ?? add(key, assistantEntry());
      e.text += delta;
      onEntry(e);
    },
    textDone(key, text) {
      const e = byKey.get(key) ?? add(key, assistantEntry());
      if (typeof text === "string" && text) e.text = text;
      e.streaming = false;
      onEntry(e);
    },
    toolStart(key, name, args) {
      onEntry(add(key, toolEntry(name, args)));
    },
    /** Finish a tool step from the MCP result. Returns the typed core error in it, or null. */
    toolDone(key, name, result, args = {}) {
      const e = byKey.get(key) ?? add(key, toolEntry(name, args));
      const f = failure(result);
      e.state = f ? "failed" : "done";
      e.result = resultLine(name, result);
      onEntry(e);
      return f;
    },
    say(text) {
      onEntry(add(Symbol("say"), assistantEntry(text, false)));
    },
    notice(text, tone = "error") {
      onEntry(add(Symbol("notice"), noticeEntry(text, tone)));
    },
    /** At the end of a turn: nothing is left streaming or running. */
    settle() {
      for (const e of entries) {
        if (e.kind === "assistant" && e.streaming) {
          e.streaming = false;
          onEntry(e);
        }
        if (e.kind === "tool" && e.state === "running") {
          e.state = "failed";
          e.result = "stopped before it finished";
          onEntry(e);
        }
      }
    },
  };
}
```

```js
// The chat's tools are exactly the motion-design MCP tools, reached through
// an in-process MCP client over createServer() (mcp/client.mjs). The MCP
// package is imported on first use, so the studio still starts when
// mcp/node_modules is missing; only the chat then says what to install.
import { usage } from "../../../cli/lib/errors.mjs";

/** JSON Schema keywords the Responses API's function parameters do not take. */
const DROP = new Set(["$schema", "propertyNames"]);
export function functionSchema(schema) {
  if (Array.isArray(schema)) return schema.map(functionSchema);
  if (!schema || typeof schema !== "object") return schema;
  return Object.fromEntries(Object.entries(schema).filter(([k]) => !DROP.has(k)).map(([k, v]) => [k, functionSchema(v)]));
}

export function createTools({ deps = {}, catalog } = {}) {
  let conn = null;
  const open = () =>
    (conn ??= import("../../../mcp/client.mjs")
      .then((m) => m.connectInProcess({ deps, catalog }))
      .catch((err) => {
        conn = null;
        if (err?.code === "ERR_MODULE_NOT_FOUND") throw usage("The chat needs the MCP package. Run: npm --prefix mcp install");
        throw err;
      }));

  return {
    async instructions() {
      return (await open()).client.getInstructions() ?? "";
    },
    /** The tools as Responses API function tools. */
    async functions() {
      const { tools } = await (await open()).client.listTools();
      return tools.map((t) => ({ type: "function", name: t.name, description: t.description ?? "", parameters: functionSchema(t.inputSchema), strict: false }));
    },
    /** A tool's result; a call the SDK itself rejects (an unknown tool, bad arguments) comes back as an error result too. */
    async call(name, args) {
      const { client } = await open();
      try {
        return await client.callTool({ name, arguments: args ?? {} });
      } catch (err) {
        return { isError: true, content: [{ type: "text", text: `Error 1: ${err.message}` }], _meta: { error: { code: 1 } } };
      }
    },
    async close() {
      if (conn) await (await conn.catch(() => null))?.close();
      conn = null;
    },
  };
}
```

The Responses API over plain `fetch`: `POST /v1/responses` with `{ model, instructions, input, tools, stream: true, store: false, parallel_tool_calls: false }`. The stream's events used are `response.output_text.delta` (`item_id`, `delta`), `response.output_item.done` (a finished message or `function_call` item with `call_id`, `name`, `arguments`), `response.completed` (`response.output`), `response.failed` (`response.error`) and `error`. For each function call the backend calls the MCP tool and sends `{ type: "function_call_output", call_id, output }` with the previous output items (without `status`, since nothing is stored), until the model answers in text, at most 24 rounds. A code-2 result ends the turn. `GET /v1/models` (free) lists the key's models; only text model families are kept, newest first. A 401 is a `ChatError` with `connect: true` and never repeats the key.

The fixtures follow the Responses API reference (looked up with context7); they were not captured from the real API, because capturing would spend.

```js
/**
 * fetch for https://api.openai.com/v1/responses and /v1/models. `replies` is
 * one entry per POST /v1/responses, in order: an event list (streamed) or
 * { status, error } (an HTTP error). `models` answers GET /v1/models.
 * `requests` records each call's url and parsed body; `auth` records whether
 * a bearer token was sent, never the token.
 */
export function fakeOpenAI({ replies = [], models = [] } = {}) {
  const requests = [];
  const queue = [...replies];
  const fetch = async (url, init = {}) => {
    const u = String(url);
    const body = init.body ? JSON.parse(init.body) : null;
    requests.push({ url: u, method: init.method ?? "GET", body, auth: /^Bearer \S+$/.test(init.headers?.authorization ?? "") });
    if (u === "https://api.openai.com/v1/models") return new Response(JSON.stringify({ object: "list", data: models }), { status: 200 });
    if (u !== "https://api.openai.com/v1/responses") throw new Error(`fake OpenAI: unexpected ${u}`);
    const next = queue.shift();
    if (!next) throw new Error("fake OpenAI: no reply left for this request");
    if (!Array.isArray(next)) return new Response(JSON.stringify({ error: next.error }), { status: next.status });
    return new Response(sse(next), { status: 200, headers: { "content-type": "text/event-stream" } });
  };
  return { fetch, requests, left: () => queue.length };
}
```

```js
// runs the loop: the model calls a function, the server calls the MCP tool,

  const { data = [] } = await res.json();
  return data
    .filter((m) => typeof m?.id === "string" && TEXT_MODEL.test(m.id) && !NOT_TEXT.test(m.id))
    .sort((a, b) => (b.created ?? 0) - (a.created ?? 0) || a.id.localeCompare(b.id))
    .map((m) => m.id);
}

/** Server-sent events from a fetch body, as parsed JSON data. */
export async function* sseEvents(body) {
  const decoder = new TextDecoder();
  let buf = "";
  for await (const chunk of body) {
    buf += decoder.decode(chunk, { stream: true }).replace(/\r\n/g, "\n");
    let cut;
    while ((cut = buf.indexOf("\n\n")) >= 0) {
      const block = buf.slice(0, cut);
      buf = buf.slice(cut + 2);
      const data = block
        .split("\n")
        .filter((l) => l.startsWith("data:"))
        .map((l) => l.slice(5).trimStart())
        .join("\n");
      if (data && data !== "[DONE]") yield JSON.parse(data);
    }
  }
}

const messageText = (item) =>
  (item.content ?? [])
    .filter((c) => c.type === "output_text")
    .map((c) => c.text)
    .join("");

/** What the model reads back from a tool: its text, then its structured data. */
function toolOutput(result) {
  const text = resultText(result);
  const data = result?.structuredContent ? `\n${JSON.stringify(result.structuredContent)}` : "";
  return `${text}${data}`.slice(0, MAX_TOOL_OUTPUT);
}

const BAD_ARGS = { isError: true, content: [{ type: "text", text: "Error 1: the arguments were not valid JSON." }], _meta: { error: { code: EXIT.USAGE } } };

/**
 * One chat turn. `sink` receives the transcript (text deltas, tool steps);
 * `tools` is createTools(). Resolves {} when the model answered, or
 * { budget: message } when a limit refused a job: the turn stops there.
 */
export async function runTurn({ key, model, instructions, history, text, tools, sink, signal, fetch }) {
  const functions = await tools.functions();
  const input = [...history, { role: "user", content: text }];
  for (let step = 0; step < MAX_STEPS; step++) {
    const res = await fetch(`${API}/responses`, {
      method: "POST",
      signal,
      headers: { ...auth(key), "content-type": "application/json" },
      body: JSON.stringify({ model, instructions, input, tools: functions, stream: true, store: false, parallel_tool_calls: false }),
    });
    if (!res.ok) throw await openaiError(res);

    let response = null;
    for await (const e of sseEvents(res.body)) {
      if (e.type === "response.output_text.delta") sink.text(e.item_id, e.delta);
      else if (e.type === "response.output_item.done" && e.item?.type === "message") sink.textDone(e.item.id, messageText(e.item));
      else if (e.type === "response.completed" || e.type === "response.incomplete") response = e.response;
      else if (e.type === "response.failed") throw new ChatError(`OpenAI could not finish the reply: ${redact(e.response?.error?.message ?? "no reason given")}`);
      else if (e.type === "error") throw new ChatError(`OpenAI error: ${redact(e.message ?? e.error?.message ?? "no message")}`);
    }
    if (!response) throw new ChatError("OpenAI's reply ended early. Send the message again.");

    const output = response.output ?? [];
    input.push(...output.map(({ status: _status, ...item }) => item));
    const calls = output.filter((item) => item.type === "function_call");
    if (!calls.length) return {};
    for (const call of calls) {
      let args;
      try {
        args = call.arguments ? JSON.parse(call.arguments) : {};
      } catch {
        args = null;
      }
      sink.toolStart(call.call_id, call.name, args ?? {});
      const result = args === null ? BAD_ARGS : await tools.call(call.name, args);
      const failed = sink.toolDone(call.call_id, call.name, result);
      input.push({ type: "function_call_output", call_id: call.call_id, output: toolOutput(result) });
      if (failed?.code === EXIT.BUDGET) return { budget: failed.message };
    }
  }
  throw new ChatError(`Stopped after ${MAX_STEPS} steps without a final answer. Ask again with a narrower request.`);
}
```

```js
// Chat turns, one film at a time each. A turn runs on the server whatever the
// page does: its entries reach every open page as SSE `chat` events
// ({ film, busy, entry }), and GET /api/chat/:film returns the saved
// transcript plus the turn in progress, so a reload or a second tab catches
// up. The user's line is saved when it is sent; the turn's other entries are
// saved, in the order they began, when the turn ends. Jobs the chat starts
// reach the feed through the job watcher (events.mjs), not through here.
import { EXIT } from "../../../cli/lib/errors.mjs";
import { redact } from "../../../cli/lib/redact.mjs";
import { HttpError } from "../http.mjs";
import { readConnection } from "./config.mjs";
import { systemPrompt } from "./prompt.mjs";
import { ChatError, appendChat, budgetSentence, createTurnLog, historyMessages, readChat, userEntry } from "./transcript.mjs";

export const MAX_MESSAGE = 8_000;
export const NOT_CONNECTED = "Chat isn't connected. Choose the ChatGPT subscription, or paste an OpenAI API key.";

/** One sentence for the page, for anything a turn throws. */
function sentence(err) {
  if (err instanceof ChatError) return err.message;
  if (typeof err?.code === "number" && err.code >= EXIT.USAGE && err.code <= EXIT.UNCERTAIN) return redact(err.message);
  return `The chat stopped on an unexpected error: ${redact(err?.message ?? String(err))}`;
}

/**
 * `backends`: { openai, codex }, each { ready(conn), turn({...}) }.
 * `publish(event)` sends an SSE event; `tools` gives the MCP instructions.
 */
export function createChat({ backends, tools, publish = () => {} }) {
  const live = new Map(); // film → { log, ctrl, done }

  const emit = (film, entry) => publish({ event: "chat", data: { film, busy: live.has(film), entry } });

  return {
    view(film) {
      const { entries } = readChat(film);
      const turn = live.get(film);
      return { film, busy: Boolean(turn), entries: turn ? [...entries, ...turn.log.entries] : entries };
    },

    /** Start a turn and answer at once with the user's entry; the rest arrives as events. */
    async send(film, text) {
      if (typeof text !== "string" || !text.trim()) throw new HttpError(400, "Write a message first.", { field: "text" });
      if (text.length > MAX_MESSAGE) throw new HttpError(400, `A message is at most ${MAX_MESSAGE} characters.`, { field: "text" });
      if (live.has(film)) throw new HttpError(409, "The chat is still answering in this film. Wait for it, or press Stop.");
      const conn = readConnection();
      const backend = conn.backend ? backends[conn.backend] : null;
      if (!backend) throw new HttpError(409, NOT_CONNECTED, { connect: true });
      const ready = await backend.ready(conn);
      if (!ready.ok) throw new HttpError(409, ready.message, { connect: true });
      if (live.has(film)) throw new HttpError(409, "The chat is still answering in this film. Wait for it, or press Stop.");

      const saved = readChat(film);
      const user = userEntry(text.trim());
      appendChat(film, [user]);
      const turn = { ctrl: new AbortController(), log: createTurnLog((e) => emit(film, e)) };
      live.set(film, turn);
      emit(film, user);

      turn.done = (async () => {
        try {
          const instructions = systemPrompt({ film, mcpInstructions: await tools.instructions() });
          const out = await backend.turn({
            conn,
            film,
            text: user.text,
            history: historyMessages(saved.entries),
            saved,
            instructions,
            sink: turn.log,
            signal: turn.ctrl.signal,
          });
          if (out?.budget) turn.log.say(budgetSentence(out.budget));
        } catch (err) {
          if (turn.ctrl.signal.aborted) turn.log.notice("Stopped.", "info");
          else turn.log.notice(sentence(err));
        } finally {
          turn.log.settle();
          try {
            appendChat(film, turn.log.entries);
          } catch (err) {
            process.stderr.write(`studio: could not save the chat for ${film}: ${redact(err.message)}\n`);
          }
          live.delete(film);
          publish({ event: "chat", data: { film, busy: false, entry: null } });
        }
      })();
      return { entry: user };
    },

    /** Stop the film's turn. True when one was running. */
    stop(film) {
      const turn = live.get(film);
      if (!turn) return false;
      turn.ctrl.abort();
      return true;
    },

    /** Films with a turn running. */
    films: () => [...live.keys()],

    /** Resolves when the film's turn (if any) has ended and been saved. Tests and shutdown. */
    async idle(film) {
      const films = film ? [film] : [...live.keys()];
      await Promise.all(films.map((f) => live.get(f)?.done));
    },
  };
}
```

```ts
import { useCallback, useEffect, useState } from "react";
import { api, ApiError } from "../api/client";
import type { ChatEntry, ChatView } from "../api/types";
import { onStudioEvent } from "../app/useStudio";

/** Put `entry` in place of the one with its id, or at the end. */
export function upsert(entries: ChatEntry[], entry: ChatEntry): ChatEntry[] {
  const i = entries.findIndex((e) => e.id === entry.id);
  if (i < 0) return [...entries, entry];
  const next = entries.slice();
  next[i] = entry;
  return next;
}

/**
 * A film's chat: the saved transcript plus the turn in progress, kept current
 * by the stream's `chat` events. `connect` is true when the server said the
 * chat is not connected (or the connection stopped working): the panel then
 * shows the two ways to connect.
 */
export function useChat(film: string | null) {
  const [entries, setEntries] = useState<ChatEntry[]>([]);
  const [busy, setBusy] = useState(false);
  const [error, setError] = useState<string | null>(null);
  const [connect, setConnect] = useState(false);

  const load = useCallback(() => {
    if (!film) return Promise.resolve();
    return api<ChatView>(`/api/chat/${encodeURIComponent(film)}`)
      .then((v) => {
        setEntries(v.entries);
        setBusy(v.busy);
      })
      .catch((e) => setError(e instanceof ApiError ? e.message : String(e)));
  }, [film]);

  useEffect(() => {
    setEntries([]);
    setBusy(false);
    setError(null);
    load();
  }, [load]);

  useEffect(
    () =>
      onStudioEvent((e) => {
        // A reconnected stream may have missed entries: read the film's chat again.
        if (e.event === "hello") load();
        if (e.event !== "chat" || e.data.film !== film) return;
        setBusy(e.data.busy);
        const entry = e.data.entry;
        if (entry) setEntries((list) => upsert(list, entry));
      }),
    [film, load],
  );

  async function send(text: string): Promise<boolean> {
    if (!film) return false;
    setError(null);
    try {
      const r = await api<{ entry: ChatEntry }>(`/api/chat/${encodeURIComponent(film)}`, { method: "POST", body: { text } });
      setConnect(false);
      setBusy(true);
      setEntries((list) => upsert(list, r.entry));
      return true;
    } catch (e) {
      if (e instanceof ApiError && e.detail.connect) setConnect(true);
      setError(e instanceof ApiError ? e.message : String(e));
      return false;
    }
  }

  async function stop() {
    if (!film) return;
    await api(`/api/chat/${encodeURIComponent(film)}/stop`, { method: "POST" }).catch(() => {});
  }

  return { entries, busy, error, connect, setConnect, send, stop };
}
```

```tsx
 * comes back: the page only learns that one is saved.

export function ConnectionForm({ initial, onSaved }: { initial: ChatSettingsView; onSaved: (view: ChatSettingsView) => void }) {
  const id = useId();
  const [choice, setChoice] = useState<ChatBackend | null>(initial.backend);
  const [view, setView] = useState(initial);
  const [codex, setCodex] = useState<CodexStatus | null>(null);
  const [checking, setChecking] = useState(false);

  const [models, setModels] = useState<string[] | null>(null);
  const [model, setModel] = useState(initial.model ?? "");
  const [error, setError] = useState<string | null>(null);
  const [busy, setBusy] = useState(false);

  async function checkCodex() {
    setChecking(true);
    try {
      setCodex(await api<CodexStatus>("/api/chat-settings/codex"));
    } catch (e) {
      setCodex({ installed: false, loggedIn: false, plan: null, message: message(e) });
    } finally {
      setChecking(false);
    }
  }

  async function loadModels() {
    try {
      const r = await api<{ models: string[] }>("/api/chat-settings/models");
      setModels(r.models);
      if (!r.models.includes(model)) setModel(r.models[0] ?? "");

      setError(message(e));
    } finally {
      setBusy(false);

          </span>
        </label>
        <label className="connect__choice">
          <input type="radio" name={`${id}-backend`} checked={choice === "openai"} onChange={() => setChoice("openai")} />
          <span>
            <span className="connect__label">OpenAI API key</span>
            <span className="connect__hint">Each message is billed to the key's OpenAI account.</span>
          </span>
        </label>
      </fieldset>

      {choice === "codex" && (
        <div className="connect__detail">
          <p className="connect__status" data-ok={Boolean(codex?.loggedIn)} aria-live="polite">

          </button>

      {choice === "openai" && (
        <div className="connect__detail">
          {view.openai.keySaved && (
            <p className="connect__status" data-ok="true">
              {view.openai.keySource === "env" ? `Key found in ${view.openai.keyEnv}.` : "Key saved."}
            </p>
          )}
          {view.openai.keySource !== "env" && (
            <div className="connect__row">

              <button type="button" className="button" disabled={!key.trim() || busy} onClick={saveKey}>

            </div>

          {view.openai.keySaved && models && (
            <div className="connect__row">
              <label htmlFor={`${id}-model`}>Model</label>
              <select id={`${id}-model`} value={model} onChange={(e) => setModel(e.target.value)}>
```

```js
// A stand-in for `codex app-server`, for tests. Run as
//   node fake-codex.mjs <exchange.json> <log.jsonl> [the real app-server args...]
// It answers initialize, account/read, thread/start, thread/resume,
// mcpServerStatus/list, turn/start and turn/interrupt from the exchange file,
// then plays the exchange's turn steps:
//   { "notify": method, "params": {...} }   a notification
//   { "request": method, "params": {...} }  a server request; waits for the answer
//   { "waitFor": method }                   waits until the client sends that method
// "$thread" and "$turn" anywhere in params become the current ids.
// A step with "early": true is sent before the turn/start response.
// The log gets { argv } first, then { in: message } for every line received.
// The shapes follow web/server/chat/codex-protocol; initialize and account/read
// are copied from a real codex-cli 0.154.0 (email replaced).
import { appendFileSync, readFileSync, writeFileSync } from "node:fs";
import { createInterface } from "node:readline";

const [exchangeFile, logFile, ...argv] = process.argv.slice(2);
const ex = JSON.parse(readFileSync(exchangeFile, "utf8"));
writeFileSync(logFile, `${JSON.stringify({ argv })}\n`);

let threadId = null;
let nextId = 1000;
const waiting = new Map(); // id or method → resolve
const send = (m) => process.stdout.write(`${JSON.stringify(m)}\n`);
const fill = (v) => JSON.parse(JSON.stringify(v ?? {}).replaceAll('"$thread"', JSON.stringify(threadId)).replaceAll('"$turn"', JSON.stringify(ex.turnId ?? "turn-1")));

async function play(steps) {
  for (const step of steps) {
    if (step.notify) send({ method: step.notify, params: fill(step.params) });
    else if (step.request) {
      const id = nextId++;
      const answered = new Promise((r) => waiting.set(id, r));
      send({ id, method: step.request, params: fill(step.params) });
      await answered;
    } else if (step.waitFor) await new Promise((r) => waiting.set(step.waitFor, r));
  }
}

function answer(m) {
  const reply = (result) => send({ id: m.id, result });
  const error = (message) => send({ id: m.id, error: { code: -32600, message } });
  switch (m.method) {
    case "initialize":
      return reply(ex.initialize);
    case "account/read":
      return reply(ex.account);
    case "thread/start":
      threadId = ex.threadId ?? "thr-new";
      return reply({ thread: { id: threadId }, model: "gpt-fake", cwd: m.params.cwd, sandbox: { type: "readOnly" } });
    case "thread/resume":
      if (ex.resume === "missing") return error(`no rollout found for thread id ${m.params.threadId}`);
      threadId = m.params.threadId;
      return reply({ thread: { id: threadId } });
    case "mcpServerStatus/list":
      if (ex.mcpStatus === "error") return error("mcpServerStatus/list failed");
      return reply({ data: ex.mcpServers ?? [], nextCursor: null });
    case "turn/start": {
      const steps = ex.turn ?? [];
      const early = steps.filter((s) => s.early);
      return play(early).then(() => {
        reply({ turn: { id: ex.turnId ?? "turn-1", items: [], status: "inProgress", error: null } });
        return play(steps.filter((s) => !s.early));
      });
    }
    case "turn/interrupt":
      return reply({});
    default:
      return error(`fake codex: no answer for ${m.method}`);
  }
}

createInterface({ input: process.stdin }).on("line", (line) => {
  const m = JSON.parse(line);
  appendFileSync(logFile, `${JSON.stringify({ in: m })}\n`);
  if (m.method && waiting.has(m.method)) {
    waiting.get(m.method)();
    waiting.delete(m.method);
  }
  if (m.id != null && !m.method) {
    waiting.get(m.id)?.();
    waiting.delete(m.id);
  } else if (m.id != null) answer(m);
});
```

```js
const DECLINED = "The studio chat cannot run commands or change files; it acts only through the motion-design tools.";
const unsupported = (method) => () => {

/**

 * Approvals are declined; questions get no answer; nothing is granted.
 */
export const ANSWERS = {
  "item/commandExecution/requestApproval": () => ({ decision: "decline" }),
  "item/fileChange/requestApproval": () => ({ decision: "decline" }),
  "item/permissions/requestApproval": () => ({ permissions: {}, scope: "turn" }),
  execCommandApproval: () => ({ decision: { denied: { rejection: DECLINED } } }),
  applyPatchApproval: () => ({ decision: { denied: { rejection: DECLINED } } }),
  "mcpServer/elicitation/request": () => ({ action: "decline", content: null, _meta: null }),
  "item/tool/requestUserInput": () => ({ answers: {} }),
  "item/tool/call": () => ({ contentItems: [], success: false }),
  "account/chatgptAuthTokens/refresh": unsupported("account/chatgptAuthTokens/refresh"),
  "attestation/generate": unsupported("attestation/generate"),
};

/** JSON-RPC over the child's stdio. */
function openRpc(child, { onNotification }) {
  let next = 1;
  const pending = new Map();
  const write = (m) => child.stdin.write(`${JSON.stringify(m)}\n`);
  createInterface({ input: child.stdout }).on("line", (line) => {
    let m;
    try {
      m = JSON.parse(line);
    } catch {
      return;
    }
    if (m.id != null && m.method) {
      const answer = ANSWERS[m.method] ?? unsupported(m.method);
      try {
        write({ id: m.id, result: answer(m.params) });
      } catch (err) {
        write({ id: m.id, error: { code: -32601, message: err.message } });
      }
    } else if (m.id != null) {
      const p = pending.get(m.id);
      if (!p) return;
      pending.delete(m.id);
      if (m.error) p.reject(Object.assign(new Error(m.error.message ?? "Codex error"), { rpc: m.error }));
      else p.resolve(m.result);
    } else if (m.method) {
      onNotification(m);
    }
  });
  child.on("exit", () => {
    for (const p of pending.values()) p.reject(new ChatError("Codex stopped."));
    pending.clear();
  });
  return {
    request(method, params) {
      const id = next++;
      return new Promise((resolve, reject) => {
        pending.set(id, { resolve, reject });
        write({ id, method, params });
      });
    },
    notify(method, params) {
      write(params === undefined ? { method } : { method, params });
    },
  };
}

/** Earlier lines of the film, for a new thread (a film whose chat began with the other backend, or whose thread is gone). */
export function recap(entries) {
  const lines = historyMessages(entries, 20).map((m) => `${m.role === "user" ? "User" : "You"}: ${m.content}`);
  return lines.length ? `Earlier in this film's chat:\n${lines.join("\n")}\n\nNow:\n` : "";
}

/**
 * A Codex MCP tool call item as an MCP tool result, for the transcript. Our
 * server's errors start "Error <code>: ", so a refusal is read from the text
 * as well, in case Codex drops the result's isError or _meta.
 */
export function toolResult(item) {
  const content = item.result?.content ?? (item.error ? [{ type: "text", text: item.error.message }] : []);
  const typed = /^Error [1-5]: /.test(content.find((c) => c?.type === "text")?.text ?? "");
  return { ...(item.result ?? {}), content, isError: item.status === "failed" || Boolean(item.error) || typed };
}

/**
 * KIE_CODEX_COMMAND replaces the codex binary (the web tests point it at a
 * path that does not exist, so no test can reach the real Codex).
 * `command` and `prefixArgs` let tests run a fake app-server
 * (process.execPath, [fake-codex.mjs, ...]); `args` builds the real
 * arguments when the process starts.
 */
export function createCodex({ command = process.env.KIE_CODEX_COMMAND || "codex", prefixArgs = [], args, repo = REPO_ROOT, keyEnvs = [] } = {}) {
  const build =
    args ??
    (() => {
      const file = codexConfigPath();
      const configText = existsSync(file) ? readFileSync(file, "utf8") : "";
      return codexArgs({ repo, keyEnvs, configText });
    });
  const listeners = new Set();
  let proc = null;

  function start() {
    if (proc) return proc.ready;
    const child = spawn(command, [...prefixArgs, ...build()], { cwd: repo, stdio: ["pipe", "pipe", "pipe"] });
    child.stderr.resume(); // Codex logs there; not ours to keep
    child.stdin.on("error", () => {}); // a write after exit; the exit handler reports it
    const rpc = openRpc(child, { onNotification: (m) => listeners.forEach((fn) => fn(m)) });
    const p = { child, rpc };
    p.ready = new Promise((resolve, reject) => {
      child.on("error", (err) => reject(err.code === "ENOENT" ? new ChatError(NOT_INSTALLED, { connect: true }) : err));
      child.once("spawn", resolve);
    })
      .then(() => rpc.request("initialize", { clientInfo: { name: "motion_design_studio", title: "Motion-design studio", version: "0.1.0" }, capabilities: null }))
      .then(() => rpc.notify("initialized"));
    child.on("exit", () => {
      if (proc === p) proc = null;
    });
    p.ready.catch(() => {
      if (proc === p) proc = null;
      child.kill();
    });
    proc = p;
    return p.ready;
  }

  function stopProcess() {
    proc?.child.kill();
    proc = null;
  }

  async function status() {
    try {
      await start();
      const r = await proc.rpc.request("account/read", { refreshToken: false });
      const a = r?.account;
      if (!a) {
        stopProcess(); // after codex login, the next check starts a Codex that sees the new login
        return { installed: true, loggedIn: false, plan: null, message: NOT_LOGGED_IN };
      }
      const plan = a.type === "chatgpt" ? `ChatGPT ${a.planType}` : a.type === "apiKey" ? "an OpenAI API key" : a.type;
      return { installed: true, loggedIn: true, plan, message: null };
    } catch (err) {
      if (err.message === NOT_INSTALLED) return { installed: false, loggedIn: false, plan: null, message: NOT_INSTALLED };
      return { installed: true, loggedIn: false, plan: null, message: `Codex did not answer: ${redact(err.message)}` };
    }
  }

  /** Refuse to run a turn when Codex has another MCP server live in the thread anyway (a plugin's, say). */
  async function guard(threadId) {
    const r = await proc.rpc.request("mcpServerStatus/list", { threadId, detail: "toolsAndAuthOnly" }).catch(() => null);
    if (!Array.isArray(r?.data)) {
      throw new ChatError("Codex did not say which tools are on for this chat, so the turn was not started. Try again, or use an OpenAI API key.");
    }
    const others = r.data.filter((s) => s.name !== MCP_NAME && ["starting", "connected"].includes(s.runtimeStatus)).map((s) => s.name);
    if (others.length) {
      throw new ChatError(
        `Codex has other MCP servers on for this chat (${others.join(", ")}). The studio's chat runs only with the motion-design tools: turn those off in ~/.codex/config.toml, or use an OpenAI API key.`,
      );
    }
  }

  async function turn({ film, text, saved, instructions, sink, signal }) {
    await start();
    const { rpc, child } = proc;
    const threadParams = { cwd: repo, sandbox: "read-only", approvalPolicy: "never", developerInstructions: instructions };
    let threadId = saved.codexThread;
    let fresh = false;
    if (threadId) {
      try {
        await rpc.request("thread/resume", { threadId, ...threadParams });
      } catch {
        threadId = null; // gone from Codex's history; start again with a recap
      }
    }
    if (!threadId) {
      threadId = (await rpc.request("thread/start", threadParams)).thread.id;
      fresh = true;
      appendChat(film, [{ kind: "codex-thread", threadId }]);
    }
    await guard(threadId);
    const input = `${fresh ? recap(saved.entries) : ""}${text}`;

    return new Promise((resolve, reject) => {
      let turnId = null;
      let budget = null;
      const early = [];
      const interrupt = () => turnId && rpc.request("turn/interrupt", { threadId, turnId }).catch(() => {});
      const finish = (fn, value) => {
        listeners.delete(onMessage);
        signal.removeEventListener("abort", interrupt);
        child.off("exit", onExit);
        fn(value);
      };
      const onExit = () => finish(reject, new ChatError("Codex stopped in the middle of the reply. Send the message again."));

      function handle(m) {
        const p = m.params ?? {};
        const item = p.item;
        switch (m.method) {
          case "item/agentMessage/delta":
            sink.text(p.itemId, p.delta);
            break;
          case "item/started":
            if (item?.type === "mcpToolCall") sink.toolStart(item.id, item.server === MCP_NAME ? item.tool : `${item.server}/${item.tool}`, item.arguments);
            break;
          case "item/completed":
            if (item?.type === "agentMessage") sink.textDone(item.id, item.text);
            if (item?.type === "mcpToolCall") {
              const f = sink.toolDone(item.id, item.server === MCP_NAME ? item.tool : `${item.server}/${item.tool}`, toolResult(item), item.arguments);
              if (f?.code === EXIT.BUDGET && !budget) {
                budget = f.message; // the chat never asks before spending: a limit's refusal ends the turn
                interrupt();
              }
            }
            break;
          case "error":
            if (!p.willRetry) sink.notice(`Codex: ${redact(p.error?.message ?? "an error")}`);
            break;
          case "turn/completed": {
            const t = p.turn ?? {};
            if (budget) finish(resolve, { budget });
            else if (t.status === "failed") finish(reject, new ChatError(`Codex could not finish the reply: ${redact(t.error?.message ?? "no reason given")}`));
            else if (signal.aborted) finish(reject, new ChatError("Stopped."));
            else finish(resolve, {});
            break;
          }
        }
      }
      function onMessage(m) {
        const p = m.params ?? {};
        if (p.threadId !== threadId) return;
        if (!turnId) return void early.push(m);
        if (p.turnId && p.turnId !== turnId) return;
        handle(m);
      }

      listeners.add(onMessage);
      signal.addEventListener("abort", interrupt);
      child.once("exit", onExit);
      rpc.request("turn/start", { threadId, input: [{ type: "text", text: input, text_elements: [] }] }).then(
        (r) => {
          turnId = r.turn.id;
          for (const m of early.splice(0)) if (!m.params?.turnId || m.params.turnId === turnId) handle(m);
          if (signal.aborted) interrupt();
        },
        (err) => finish(reject, err),
      );
    });
  }

  return {
    name: "codex",
    status,
    async ready() {
      const s = await status();
      return s.loggedIn ? { ok: true } : { ok: false, message: s.message };
    },
    turn: ({ conn: _conn, ...rest }) => turn(rest),
    close: stopProcess,
  };
}
```

## Decisions for the reviewer

1. **SSE, not a streamed POST.** See "How the chat reaches the page". The cost is that a turn's non-user entries are saved only when the turn ends; a server crash mid-turn loses that turn's lines (the user's line is already saved, and jobs are in core's job records either way).
2. **The tools are the MCP server, in process.** `mcp/client.mjs` links an SDK client to `createServer()` in memory, so the API-key chat has the same 18 tools, input checks, limits and error codes as Claude Code and Codex. The web server imports it lazily: if `mcp/node_modules` is missing the studio still starts and the chat says to run `npm --prefix mcp install`.
3. **Codex sees only motion-design.** It starts our MCP server from `-c` overrides with the studio's runs, library and limits paths; every MCP server named in `~/.codex/config.toml` is disabled by name, and the features that bring their own tools are disabled (plugins, apps, computer and browser use, the in-app browser, image generation, sub-agents, the shell). A server Codex would still start (from a plugin config the regex cannot see) is caught before the turn by `mcpServerStatus/list`; if that call fails, the turn does not run. Codex's built-in web search is off (`web_search="disabled"`), so nothing from the web reaches a chat that spends without asking.
4. **Approvals are declined, not shown.** The read-only sandbox and `approvalPolicy: "never"` mean Codex should not ask; anything it does ask is declined (`ANSWERS`), and our MCP tools are pre-approved with `default_tools_approval_mode="approve"` so a paid call is never held for a confirmation the page cannot give. Codex command and file-change items are not shown as tool steps (with the shell off there should be none).
5. **A code-2 refusal ends the turn in both backends.** The OpenAI loop stops calling the model; Codex gets `turn/interrupt`. The assistant's last line is core's reason (everything before "Ask the user") plus the way out. Codex is detected from `isError`, `_meta.error.code` or, if Codex drops both, the `Error 2:` prefix of the text.
6. **Recorded exchanges.** No real turn was run for either backend (that would spend). The OpenAI fixtures follow the Responses API reference; the Codex exchanges use the real `initialize` and `account/read` replies and turn shapes built from the generated types. The drift test fails when the installed Codex's version changes, with the command to regenerate.
7. **One Codex process, kept.** The first status check starts `codex app-server` and later turns reuse it; it stops on a logged-out check (so `codex login` is seen) and on shutdown. Each film keeps its own Codex thread id in `chat.jsonl`; a film whose chat began with the API key, or whose thread Codex no longer has, gets a recap of its last 20 lines in the first message of the new thread. The API-key backend sends the last 40 user and assistant lines each turn.
8. **The key.** Saved mode 600 through a temp file and rename; `OPENAI_API_KEY` wins when set (and then the page offers no key field). Responses say only whether a key is saved and where it comes from; a refused paste is not echoed; errors from OpenAI are redacted. The model list is `GET /v1/models` filtered to text model families, because the endpoint says nothing about capabilities.
9. **The job-in-the-feed test uses the API-key path** (Task 6), where the stubbed provider makes a real local job record. Codex's MCP server is a separate process in tests too (the fake does not run it), so the Codex path's job reaching the feed rests on the same watcher and the same runs folder, passed in `env`.
10. **What the spec asked for that is not here.** Nothing is left out. Two limits: the Codex backend has only been exercised against the fake app-server and a real `initialize`/`account/read`, never a real turn; and whether Codex validates the motion-design `-c` entries at startup or only when a thread starts the server is not known, so a wrong path would surface as a turn error ("The chat stopped on an unexpected error: …").
